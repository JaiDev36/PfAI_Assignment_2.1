# NumCompute

A NumPy-only toolkit for loading, preprocessing, ranking, sorting, summarising and scoring data, written for COMP 5004, Assignment 2.1, Programming Task 1, by Edward Coombs, Jaidev Parthiban and Sai Siriza Gaddam.

- Setup, examples, API overview and performance table: [NumCompute/README.md](./NumCompute/README.md)
- Code: `NumCompute/numcompute/`
- Tests: `NumCompute/tests/`
- Benchmarks: `NumCompute/benchmark/`
- Demo notebook: `NumCompute/demo/quickstart.ipynb`

Assignment 2.2, Programming Task 2 (individual, Jaidev Parthiban, branch `feature/stream-2.2`): `numcompute_stream`, a streaming extension of NumCompute with a buffered decision tree.

- Package and usage: [NumCompute/numcompute_stream/README.md](./NumCompute/numcompute_stream/README.md)
- Streaming demo: `NumCompute/demo/stream_demo.ipynb`
- Streaming benchmark: `NumCompute/benchmark/bench_stream.py`, results in `NumCompute/benchmark/results_stream.md`
